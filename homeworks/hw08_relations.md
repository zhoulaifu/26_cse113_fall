# Homework08: Relations

## Exercise 1 (100 points)

For each relation below, determine whether it is reflexive, symmetric, and transitive, and whether it is an equivalence relation. Fill in the table with **T** for true or **F** for false. You do not need to explain your answers. Each relation is worth 10 points.

1. Consider the relation $R = \lbrace(a,a), (b,b), (c,c), (d,d), (a,b), (b,a)\rbrace$ on the set $A = \lbrace a, b, c, d \rbrace$.
2. Consider the relation $R = \lbrace(a,b), (a,c), (c,b), (b,c)\rbrace$ on the set $A = \lbrace a, b, c \rbrace$.
3. Consider the relation $R = \lbrace(0, 0), (2, 0), (0, 2), (2, 2)\rbrace$ on the set $A = \lbrace 0, 2 \rbrace$.
4. Define a relation $R$ on the integers by $x R y$ if $|x - y| < 1$.
5. Let $A$ be the set of people living in the world today. Define a relation $R$ on $A$ by $p R q$ if $p$ lives within 100 miles of $q$.
6. Define a relation $R$ on the integers by $x R y$ if $x \leq y$.
7. Define a relation $R$ on the integers by $x R y$ if $x - y$ is even.
8. Define a relation $R$ on the integers by $x R y$ if $x + y = 0$.
9. Define a relation $R$ on $\mathbb{Z} \times \mathbb{Z}$ by $(a, b) R (c, d)$ if $a + d = b + c$.
10. Define a relation $R$ on $\mathbb{Z} \times \mathbb{Z}$ by $(a, b) R (c, d)$ if $a = c$ or $b = d$.
